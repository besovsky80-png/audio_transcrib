# Call Audio Pipeline

Полноценный воспроизводимый пайплайн потоковой обработки аудио звонков.

## Возможности

- Приём аудио через WebSocket
- Voice Activity Detection (VAD)
- Распознавание речи (ASR)
- Диаризация спикеров
- Сохранение аудио и транскриптов
- REST API для получения результатов
- Веб-интерфейс для мониторинга
- Мониторинг и метрики

## Быстрый старт

```bash
git clone <repository-url>
cd call-audio-pipeline
cp .env.example .env
docker-compose up -d
make upgrade-db
make simulate-call
```

## Важные уведомления о приватности

⚠️ **Внимание**: Система обрабатывает аудиозаписи звонков.

- Запрещено загружать реальные персональные данные без согласия участников
- Для тестов используются синтетические аудио или тестовые записи
- Требуется явное согласие на обработку аудио (`consent_given: true`)
- Поддерживается политика хранения данных с автоматическим удалением

Подробнее см. [docs/privacy.md](docs/privacy.md)

## Формат аудио

Минимальные требования:
- PCM 16-bit
- 16000 Hz
- mono

Также поддерживается:
- stereo (для разделения агент/клиент)
- RTP (через адаптер телефонии)
- WebRTC (браузерный источник)
